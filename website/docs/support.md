# Support

Raticode is built by one developer, in the open. Help happens on GitHub.

## Check the guides first

- [Troubleshooting](./reference/troubleshooting.md) covers installation, providers, workflow validation, saved state and paired devices.
- [Installation](./installation.md) has the unsigned-build prompts for macOS and Windows, and how to check a download against its checksum.
- Search these guides with the search box at the top of the page.

## Report a bug or ask for a feature

Open an issue at [github.com/zacharyivie/Raticode/issues](https://github.com/zacharyivie/Raticode/issues). For a bug, include:

- the Raticode version (**Settings > Developer** lists runtime versions; for the CLI run `Raticode --version`) and your operating system;
- what you did, what you expected and what happened instead;
- the exact error text, and the workflow file if a workflow failed. Remove secrets, tokens and private paths first.

If the desktop app crashed, its crash screen has **Open an issue**, which fills in the error details for you to review.

## Report a security problem

Don't put the details of a security problem in a public issue. Open an issue titled "Security report" that says only how to reach you, and the maintainer will arrange a private channel.

## Releases and changes

Every desktop release, with its notes and checksums, is on [GitHub Releases](https://github.com/zacharyivie/Raticode/releases). Choose **Watch > Custom > Releases** on the repository to hear about new ones.
