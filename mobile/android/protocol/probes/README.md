# Public cryptographic interoperability probes

Everything in `public-test-identities` is public dummy material. The private keys
and cleartext Tink keyset are deliberately public test vectors. Never use them
for an invitation, signing, deployment, trust registry or real data. Application
source sets do not package these resources; only JVM and instrumentation tests do.

PEM identities and the Python streaming ciphertext originate in the Desktop
developer's protocol attempt. The Java streaming ciphertext was generated by the
mobile JVM probe and independently decrypted in the Python suite. The fixture
manifest hashes the exact bytes; TLS handshakes use fresh randomness and are
tested as live library exchanges rather than claimed deterministic transcripts.

The `expired` and `p384` certificates intentionally violate the selected profile.
They must fail even when their SPKI pin matches. `other` is a valid but untrusted
identity for wrong-pin tests.

The schemas are in `src/gofer/devices/protocol/v2` at the repository root. No real messages, paid model
calls, public relay traffic or workflow execution occurs in these probes.
