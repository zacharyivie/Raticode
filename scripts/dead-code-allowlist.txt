# Names scripts/check-dead-code.py may report but Raticode keeps on purpose.
# One per line, with the reason after a '#':
#
#   name  # reason
#   src/gofer/module.py:name  # reason, for that file only
#   .library-*  # reason, for CSS classes; * and [...] patterns work there
#
# Delete unused code rather than listing it here. A name belongs here only when
# something outside this repository calls it, or a framework calls it by a name
# the check can't see. A path:name, route or CSS line that matches nothing fails
# the check, so delete a line with the code it excused.
#
# Code only tests call stays only as a test seam: a reason that starts with
# "test seam:" says what the tests use it for. Otherwise remove it and test the
# production path instead.
